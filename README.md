# Adarsh Singh — Portfolio

Professional portfolio site for Adarsh Singh, full-stack web developer.

## Stack

- React 19
- Vite
- Tailwind CSS

## Commands

```bash
npm install
npm run dev
npm run build
npm run preview
```

## Deploy

Build static assets with `npm run build` and deploy the `dist` folder (Vercel, Netlify, GitHub Pages, etc.).
